# Serge

A Serge Modular system for VCV Rack 2: 19 modules modelled on the classic Serge circuits, with paperface-style panels and accurate text labels.

Nothing is built yet. The full specification for the implementer is in [docs/BUILD-INSTRUCTIONS.md](docs/BUILD-INSTRUCTIONS.md). The research and first proposal behind it are in [docs/design/01-research-and-proposal.md](docs/design/01-research-and-proposal.md).
