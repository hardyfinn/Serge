# Credits

- Circuit designs: Serge Tcherepnin and Serge Modular Music Systems. Behaviour taken from the 1983 Serge catalog and data sheets, Serge's kit notes as published with the CGS (Ken Stone) boards, Random*Source documentation, the NYU IDM Serge guide, serge.sublevel9.net, and Richard Brewster's SSG measurements. Full list in docs/BUILD-INSTRUCTIONS.md §12.
- Panel lettering: glyph outlines from DejaVu Sans Bold (Bitstream Vera licence / public domain changes), converted to paths.
- Pink noise filter: Paul Kellet's refined pinking filter (public domain).
- Zero-delay-feedback state-variable filter: after Vadim Zavalishin, "The Art of VA Filter Design" (formulas, no code copied).
- Round two (WAD, FRS, BDR, PDIV): behaviour from the Serge catalog descriptions, the CGS208 Wilson Analog Delay and CGS88 router build notes, and the NYU IDM Serge guide. The Pulse Divider is a Ken Stone (CGS) design. Full list in docs/BUILD-INSTRUCTIONS-ROUND-2.md §8.
- Frequency shifter phase network: pole frequencies fitted for this plugin (6 + 6 first-order all-pass sections).
- No code was copied from other plugins.
